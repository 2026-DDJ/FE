# 설문과 AI 모델 기준

검토 기준: [AI main, 9de9035](https://github.com/2026-DDJ/AI/tree/9de9035ce05f5d3768221e87dc2574ff54340a9c)의 `api/main.py`, `src/predict.py`, `src/train_final_model.py` 및 저장된 모델 3개.

## 4단계 설문

| 단계 | 항목 |
| --- | --- |
| 1 생활·경제 정보 | 가구원 수, 거주 지역, 직업군, 연간 소득 |
| 2 건강 상태·생활 습관 | 키, 몸무게, 운동 여부, 주관적 건강상태, 활동 제한, 불안·우울 |
| 3 최근 1년 의료 이용 | 외래 이용 횟수, 치과 이용 횟수, 입원 여부 |
| 4 보험 정보 | 건강보험 유형, 실손보험 가입 여부 |

`src/utils/assessmentFields.js`가 선택지·검증·AI 요청 변환의 기준이다. 사용자가 제공한 매핑을 반영했다.

- 소득: 2,400 미만 → 1570.5 / 2,400 이상 4,500 미만 → 3380 / 4,500 이상 7,500 미만 → 5880 / 7,500 이상 → 10160 (만원).
- 지역: 서울 11, 부산 26, 대구 27, 인천 28, 광주 29, 대전 30, 울산 31, 세종 36, 경기 41, 강원 42, 충북 43, 충남 44, 전북 45, 전남 46, 경북 47, 경남 48, 제주 50.
- 직업군: 관리자 14, 전문가·관련종사자 24, 사무 31, 서비스 42, 판매 52, 농림·어업 61, 기능원 78, 장치·기계조작·조립 87, 단순노무 94, 경제활동 안 함 `null`.
- 건강보험: 직장 가입자 1, 직장 피부양자 2, 지역 세대주 3, 지역 세대원 4, 의료급여(1·2종) 세대주 5, 의료급여 세대원 6, 국가유공자 7, 미가입 `null`.
- 건강상태: 매우 좋음~매우 나쁨 1~5. 운동: 예 1 / 아니오 2. 실손보험·입원: 가입·있음 1 / 미가입·없음 0. 활동 제한·불안·우울: 없음 1 / 다소 있음 2 / 심함 3.

가구원 수는 1~10 정수, 이용 횟수는 0 이상의 정수, 키·몸무게는 양의 유한수다. 모든 답변을 입력해야 다음 단계로 갈 수 있고 이전 단계 미입력 시 해당 단계로 안내한다. 입력은 같은 탭의 sessionStorage(v3)에 저장한다. 과거 소득 구간과 새 구간의 혼동을 피하도록 이전 v2 데이터는 재사용하지 않는다.

`toPredictionInput`은 위 15개 답변을 AI의 `MedicalCostInput` 규격으로 변환한다. BMI와 치과 비율은 AI API에서 계산하므로 요청에 중복 추가하지 않는다. 의료이용 상세 변수 13개는 API가 대표값으로 채운다.

## 주요 영향요인 Top 3

현재 AI API 응답은 `success`, `predictedAnnualMedicalCost`, `highCostProbability`뿐이다. SHAP, 개인별 기여도, Top 3 산출 코드는 없다. 최종 예측은 분류 확률 p를 이용한 `(1-p) × 일반 모델 예측 + p × 고액 모델 예측 × 1.05`다. 이 혼합 예측의 개인별 중요도를 모델 중요도의 임의 평균으로 대체하지 않았다.

결과 카드에서는 저장된 XGBoost 모델 3개에서 실제 추출한 **모델 전체의 변수 중요도**를 모델별로 선택해 볼 수 있다. 기본 선택은 일반 의료비 예측 모델이다. 개인의 설문 답변에 따라 순위가 바뀌지 않으며, 개인별 의료비 기여율이나 증감 방향을 의미하지 않는다. 예측 금액·비교 집단·시뮬레이션은 여전히 UI 예시이고 결과 화면에서도 표시한다. 이번 변경은 API 서버 호출을 추가하지 않는다.

추출 방법:

1. 각 모델의 `prep.get_feature_names_out()`과 `model.feature_importances_`를 대응한다. XGBoost 트리의 기본 중요도는 분할 평균 이득인 gain이다.
2. 원핫 인코딩된 범주들의 정규화 gain을 원래 변수 단위로 합산한다.
3. 전체 28개 변수 중요도 합을 100%로 정규화하고 내림차순으로 Top 3를 표시한다. 상위 3개만으로 다시 100%를 만들지 않는다.
4. 서로 다른 세 모델은 각각 순위를 표시한다. 범주 개수가 많은 변수는 합산 시 높은 순위를 얻을 수 있으며, 이 값은 SHAP이나 인과적 설명이 아니다.

| 모델 | Top 3 (전체 변수 중 중요도 비중) |
| --- | --- |
| 일반 의료비 예측 | 직업군 14.0%, 총 의료이용 일수 12.3%, 건강보험 유형 10.3% |
| 고액 의료비 예측 | 거주 지역 13.8%, 직업군 11.5%, 입원 사유(코드 2) 횟수 10.0% |
| 고비용군 분류 | 가구원 수 17.1%, 거주 지역 11.5%, 총 의료이용 일수 7.8% |

의료이용 코드의 구체적인 의미는 저장소에 코드북이 없어 임의로 질환명 등으로 해석하지 않았다.

스냅샷은 `src/data/modelImportance.json`에 원본 SHA·모델 SHA256·28개 변수별 값과 함께 저장한다. 원본 모델을 신뢰할 수 있는 경우에만 아래 명령을 실행한다. scikit-learn 1.7.2 / XGBoost 3.4.1 / joblib 환경에서 재생성했다.

```sh
python scripts/export_model_importance.py /path/to/AI
node --test tests/assessment.test.js
npm run build
npm run lint
```

개인별 Top 3를 제공하려면 최종 혼합 예측 함수를 설명하는 기여도 산출 방식을 AI 서버에 구현하고 응답 규격을 확장해야 한다.
