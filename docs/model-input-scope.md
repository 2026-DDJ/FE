# 설문과 AI 입력 범위

검토 기준: [AI main, cc24afa](https://github.com/2026-DDJ/AI/tree/cc24afa209bf822531b74e2e826bfb39f3032375)의 `src/final_22feature_validation_2024.py`, `src/final_28feature_validation_2024.py`에 선언된 `FEATURES`.
README의 15개 변수 설명보다 실제 22/28개 변수 스크립트를 기준으로 기존 설문을 정리했다.

| 단계 | 유지 항목 | 모델과의 관계 |
| --- | --- | --- |
| 1 기본 정보 | 거주 지역, 연간 소득 | `region1`, `income` |
| 2 건강 정보 | 키, 몸무게, 전반적인 건강 상태 | 키/몸무게로 `bmi` 계산, `self_rated_health` |
| 3 건강 행태 | 운동 | `exercise` |

기존 항목 중 출생년도, 성별, 만성질환 여부, 흡연, 음주는 위 스크립트의 입력에 없어 제거했다. 거주 지역은 모델 변수이므로 유지했다. 결과의 연령·성별 비교 문구도 수집하지 않는 인구통계에 맞춘 실제 분석으로 오해하지 않도록 예시 비교 집단으로 변경했다.

이 설문은 **기존 UI와 모델 입력의 교집합**이며 전체 추론 요청 규격이 아니다. 보험·입원·외래·치과·활동 제한·불안/우울·상세 의료이용 집계 등 추가 변수는 아직 수집하지 않는다. 지역/소득 구간/건강 상태/운동의 실제 KHP 코드 변환과 누락 변수 처리 방침도 AI 연동 시 별도로 확정해야 한다.

백엔드/AI 호출은 추가하지 않았다. 결과 금액·영향요인·비교 집단 및 시뮬레이션 계산은 예시다. 시뮬레이션은 BMI·운동만 조절하며, 동일 탭의 설문 입력을 기준으로 시작한다. 의료비 기준값은 결과 페이지와 공유한다. 임의 위험 등급과 중복 설명은 제거했다.

비교 그래프는 전체 평균 대비 차액을 공통 0원 기준의 가로 막대로 표시한다. 원래 의료비와 부호 있는 차액을 함께 표시해 총액과 차액을 구별한다. 기존 막대의 `max-height` 제한으로 값이 달라도 높이가 같아지던 문제를 없앴다.
